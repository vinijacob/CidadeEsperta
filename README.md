# Sobre o projeto

> O Cidade Esperta é um projeto desenvolvido para a faculdade na disciplina Atividade Prática de Extensão III.

A proposta é criar um aplicativo educativo voltado para crianças e adolescentes, onde os usuários ajudam uma cidade a resolver diferentes problemas por meio de desafios de lógica e programação.

O objetivo é transformar o aprendizado de programação em uma experiência simples, visual e divertida.

# Objetivos

- Desenvolver o raciocínio lógico
- Introduzir conceitos básicos de programação
- Estimular a resolução de problemas
- Tornar o aprendizado mais interativo e acessível

# Tecnologias

1. React Native
2. Expo
3. TypeScript

# Executar o projeto

```
npm install

npx expo start
```

> Depois, abra o projeto pelo Expo Go, emulador Android/iOS ou navegador.
